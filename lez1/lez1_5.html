Il doppio ciclo

Il ciclo esterno sceglie una riga; quello interno visita, una alla volta, tutte le colonne di quella riga.

← Precedente Successiva →

Idea chiave

Per visitare tutte le celle servono due cicli: r varia da 0 a R - 1, mentre per ogni riga c riparte da zero e arriva a C - 1.

La scansione standard per righe

Il corpo viene eseguito R * C volte. Con una matrice 3 × 4, le celle visitate sono 12.

Ordine della visita

(0,0) (0,1) (0,2) (0,3) (1,0) (1,1) (1,2) (1,3) (2,0) (2,1) (2,2) (2,3)

Questo ordine segue le righe contigue in memoria.

Visita per colonne

Non è sbagliata: si usa quando il problema richiede di elaborare una colonna alla volta.

Regola pratica: per leggere, stampare o elaborare l’intera matrice, parti dalla scansione per righe. Cambia ordine solo quando il problema lo richiede.
Trova l’errore

Il ciclo è corretto per una matrice R × C?

Mostra risposta Nascondi risposta

No: il secondo limite deve essere c < C. L’errore può restare nascosto se si prova il programma soltanto con matrici quadrate.

Tabellina rettangolare

Riempi una matrice 3 × 5 assegnando m[r][c] = (r + 1) * (c + 1). Prima di eseguire il programma, prevedi la terza riga.
