Matrici nelle funzioni C

In C, quando una matrice è un parametro, la funzione deve conoscere la lunghezza di ogni riga per calcolare correttamente m[r][c].

← Precedente Successiva →

Idea chiave

Per una matrice statica, la forma più semplice è fissare il numero di colonne e passare separatamente il numero di righe usate.

Una firma standard e leggibile

La prima dimensione può essere omessa nel parametro; C no, perché determina il passo necessario per raggiungere la riga successiva.

Perché qui non usiamo const? Nel C11 rigoroso, passare una normale matrice int[R][C] a un puntatore a righe di const int non è portabile. La funzione si impegna comunque, per contratto, a non modificare le celle.

Il tipo effettivo

Nel parametro, m[][C] viene trattato come puntatore a una riga di C interi:

int (*)[C]

Non è int**

Una matrice int dati[R][C] è un unico blocco di righe contigue. int** descrive invece un puntatore a puntatore: è un tipo diverso e non può ricevere correttamente dati.

Estensione C99

Dimensioni determinate a runtime

Mostra approfondimento Nascondi approfondimento

I VLA appartengono al C, non al C++ standard, e il loro supporto può dipendere dalla versione e dal compilatore. Le dimensioni devono essere positive quando la funzione viene chiamata. Per il ripasso di base manteniamo C costante.

Controllo rapido

Quale firma accetta int a[4][3]?

  • void f(int righe, int m[][3])
  • void f(int **m)
  • void f(int righe, int m[][4])
Mostra risposta Nascondi risposta

La prima firma, void f(int righe, int m[][3]), è compatibile in C11. int** è un tipo diverso, mentre l’ultima firma dichiara righe da quattro colonne anziché tre.
