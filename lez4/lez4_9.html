Consultare senza modificare: i metodi const

Un metodo di consultazione deve poter leggere lo stato senza cambiarlo.

← PrecedenteSuccessiva →

Const dopo le parentesi

Il nostro metodo leggiLivello() legge soltanto il campo. Lo dichiariamo const scrivendo la parola dopo le parentesi, non davanti al tipo restituito.

In questa classe un metodo const può leggere livello, ma il compilatore gli impedisce di assegnargli un nuovo valore. I metodi che caricano o consumano devono invece poter modificare il campo e non sono const.

Un oggetto const si può consultare

Il const prima del tipo rende costante l'oggetto riserva; quello dopo le parentesi permette di chiamare il metodo anche su un oggetto costante. Una chiamata di modifica non è invece ammessa:

Checkpoint

Un metodo const restituisce necessariamente un valore costante?

Mostra rispostaNascondi risposta

No. Qui const riguarda l’uso dell’oggetto durante la chiamata, non il valore numerico restituito. Il metodo restituisce un normale int.

Prova tu

Quali metodi possono essere const?

Valuta leggiLivello(), caricaCompleta(), consuma(...) e ricarica(...). Guarda l’effetto sullo stato, non il fatto che restituiscano o meno un valore.

Mostra soluzioneNascondi soluzione

Solo leggiLivello(): gli altri metodi devono poter cambiare il livello. Restituire un bool non rende automaticamente un metodo di sola consultazione.
