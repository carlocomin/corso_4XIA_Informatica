Anatomia minima di una classe

Obiettivo della pagina

Vedere la struttura minima di una classe C++ e capire il ruolo dei suoi pezzi principali.

Idea chiave: una classe minima mette in chiaro tre cose: stato interno, operazioni pubbliche e confine tra i due.

Struttura base

class Punto {
private:
    double x_ = 0.0;
    double y_ = 0.0;
public:
    double x() const { return x_; }
    double y() const { return y_; }
    void sposta(double dx, double dy){
        x_ += dx;
        y_ += dy;
    }
};
  • membri dati: descrivono lo stato dell'oggetto;
  • metodi: descrivono le azioni o le osservazioni possibili;
  • sezioni di accesso: stabiliscono chi puo usare cosa.

Classe e oggetto non sono la stessa cosa

La classe e il modello. L'oggetto e un'istanza concreta di quel modello.

Punto p;
Punto q;

p e q hanno lo stesso tipo, ma non necessariamente lo stesso stato.

struct o class?

In C++ hanno quasi le stesse capacita. La differenza pratica di base e il default di accesso:

  • struct ha membri pubblici di default;
  • class ha membri privati di default.

Regola didattica utile: usa struct per record molto semplici; usa class quando vuoi difendere invarianti e progettare un'interfaccia.

Errore tipico: pensare che una classe sia "solo una struct con metodi". In realta il punto non e aggiungere metodi, ma progettare un confine corretto tra uso esterno e stato interno.
