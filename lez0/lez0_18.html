Array passati a funzione

Un parametro scritto come array rappresenta un puntatore al primo elemento: la lunghezza deve essere comunicata separatamente.

← Precedente Successiva →

Puntatore più dimensione

Idea chiave: nei parametri, int a[] e int* a indicano lo stesso meccanismo. La funzione non può dedurre quanti elementi siano validi.

const int a[]

La funzione può leggere gli elementi, ma non modificarli.

int a[]

La funzione può modificare gli elementi del chiamante.

int n

Definisce l’intervallo valido 0..n-1. Il chiamante deve garantire 0 <= n e almeno n celle accessibili.

Errore tipico: usare sizeof(a) dentro la funzione per cercare la lunghezza. Lì a è un puntatore, non l’array originale.

Mostra risposta Nascondi risposta

Il parametro riceve l’indirizzo del primo elemento. Le espressioni a[i] raggiungono quindi le celle dell’array originale.

Ricerca riutilizzabile

Trasforma la ricerca lineare in int cerca(const int a[], int n, int valore). Provala con valore presente, assente, duplicato e array logico vuoto.

Prossimo passo. In C++ un riferimento offre una sintassi più diretta quando un parametro deve essere un alias valido.
