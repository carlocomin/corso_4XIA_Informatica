Un array, molti valori

Un array assegna un solo nome a una sequenza di elementi omogenei, distinguendoli tramite un indice.

Una sequenza a dimensione fissa

Idea chiave: un array contiene elementi dello stesso tipo, memorizzati in posizioni consecutive e numerate a partire da zero.

Leggiamo voti

07
18
26
39
48

voti[2] seleziona il terzo elemento, che vale 6. L’indice descrive una posizione, non il valore contenuto.

In C: indici e celle funzionano allo stesso modo; una forma equivalente è enum { N = 5 }; int voti[N] = {7, 8, 6, 9, 8};.

Dimensione fisica

N stabilisce quante celle esistono. In un array statico non cambia durante l’esecuzione.

Tipo omogeneo

Ogni cella è un int. Non possiamo inserire una stringa in una posizione dell’array.

Checkpoint · Traduci le espressioni

voti[0] è il primo elemento; voti[N - 1] è l’ultimo; voti[2] = 7 cambia il terzo elemento.
