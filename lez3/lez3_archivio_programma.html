Programma completo e collaudo

Una sequenza di operazioni già scritte nel main, con file iniziali separati dai risultati.

← PrecedenteSuccessiva →

Una dimostrazione, non un gestionale interattivo

Il programma esegue una sequenza già scritta nel main: carica → aggiunge → modifica → rimuove → salva → rilegge. Non chiede dati da tastiera e non ha un menu.

Usiamo record nel formato previsto e numeri corretti. Restano i controlli essenziali su apertura dei file, letture, valori, capacità dell’array e matricole duplicate.

Il materiale da usare

  • archivio_studenti.cpp · programma completo, senza parti da completare.
  • studenti_spazi.txt · file iniziale a spazi.
  • studenti.csv · gli stessi dati iniziali in CSV, per le prove.

Metti i file nella cartella di lavoro del programma, che non coincide necessariamente con la cartella del sorgente. Mantieni la codifica UTF-8.

Input e output hanno nomi diversi: il main legge studenti_spazi.txt e scrive studenti_aggiornati.txt e studenti_aggiornati.csv. I file iniziali non vengono modificati: puoi rieseguire la dimostrazione e ottenere gli stessi risultati.

Leggi il main dall’alto verso il basso

Ogni chiamata svolge un solo lavoro. Le funzioni sono definite prima del main nel file scaricabile. Se un’operazione fallisce, return 1 ferma il programma.

La seconda lettura carica dal CSV appena scritto: la stampa finale non usa soltanto i dati rimasti in memoria dopo le modifiche.

Tutto il sorgente

Studia un blocco alla volta: modello, operazioni sull’array, file a spazi, CSV e main. Non è necessario imparare l’intero programma a memoria.

Una variante

Un nome con uno spazio

Nel main cambia il record aggiornato in {1002, "Alan Turing", 5}. Togli la chiamata a salvaSpazi e salva soltanto il CSV. Quale riga troverai per 1002? Perché non usiamo il file a spazi?

Mostra soluzioneNascondi soluzione

La riga è 1002;Alan Turing;5. Il nome resta un solo campo nel CSV. Il salvataggio a spazi presuppone invece nomi di una parola: non lo chiamiamo su un archivio con nomi composti.
