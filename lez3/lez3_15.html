Le posizioni sono espresse in byte per questi file binari. Non sono né valori dei dati né indirizzi di memoria.

1. seekg: sposta la lettura

I frammenti sono da mettere in un main C++ con <fstream>, <iostream> e using namespace std;. Il file è quello con 10, 20, 30.

ios::beg significa “dall’inizio”. Saltiamo il primo int: la prossima lettura partirà dal secondo. seekg non legge il numero.

2. tellg: dove leggerò?

Continuiamo sullo stesso stream in, subito dopo il seek:

Con int da 4 byte otteniamo, nell’ordine: 4, 20, 8. Prima siamo all’inizio del secondo int; poi leggiamo 20; infine siamo dopo quel blocco. tellg() si limita a chiedere la posizione: non la sposta.

3. seekp: sposta la scrittura

Ora apriamo il file per aggiornare il secondo int senza cancellare gli altri:

La modalità in | out apre il file esistente in lettura e scrittura, senza trunc. seekp prepara la posizione; è write a sostituire i byte del secondo intero. Per ora scegliamo una posizione di cui conosciamo l’esistenza.

4. tellp: dove scriverò?

Continuiamo sullo stesso stream io, dopo la scrittura:

La posizione è 2 * sizeof(int): 8 se l’int occupa 4 byte. Rileggendo il file troviamo 10, 99, 30; la dimensione non cambia. Anche tellp() non modifica la posizione.

Da ricordare: tellg e tellp restituiscono una posizione, oppure -1 in caso di errore. Qui la stampiamo dopo operazioni controllate. Se una lettura ha già fallito, riapri il file prima di riprovare questi esempi.
Checkpoint

seekp da solo cambia 20 in 99?

Mostra rispostaNascondi risposta

No. Sposta soltanto la posizione. La modifica avviene quando la successiva write scrive i byte di 99.

Prova tu

Aggiorna il terzo valore

Quale sola parte del frammento seekp cambieresti per sostituire il terzo int con 99? Quanto varrebbe tellp dopo la scrittura?

Mostra soluzioneNascondi soluzione

Userei io.seekp(2 * sizeof(int), ios::beg). Dopo la scrittura tellp() sarebbe 3 * sizeof(int), cioè 12 con int da 4 byte. Il file conterrebbe 10, 20, 99, se si parte dai dati originali.

Ora sai fare il minimo necessario: scrivere, leggere, spostarti e conoscere la posizione. L’esercizio binario finale riprende soltanto questi gesti.
