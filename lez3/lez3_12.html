Binario: tre interi in un file

Un solo esempio per tutte le prossime slide: i valori 10, 20 e 30, scritti uno dopo l’altro.

← Precedente Successiva →

Un formato davvero piccolo

Idea chiave: il file dati.bin contiene esattamente tre int consecutivi, nell’ordine 10, 20, 30. Nessuna intestazione e nessun separatore.

Come lo immaginiamo

int: 10→int: 20→int: 30

Ogni blocco occupa sizeof(int) byte. Non sono le cifre in un file di testo: sono i byte che rappresentano quei numeri nella memoria del nostro programma.

IndiceValorePosizione iniziale nel file
0100
120sizeof(int)
2302 * sizeof(int)

Se un int occupa 4 byte, le posizioni iniziali sono 0, 4, 8 e il file occupa 12 byte. Nel codice usiamo sempre sizeof(int), non il numero 4 scritto a mano.

Che cosa deve sapere il lettore?

Deve sapere che ci sono tre valori di tipo int. Il file non contiene automaticamente né il tipo né il numero degli elementi.

Per questi esempi salviamo e rileggiamo nello stesso ambiente del laboratorio. Non supponiamo che il file funzioni su qualsiasi computer.

Checkpoint

Quanto vale la posizione iniziale del primo numero?

Mostra rispostaNascondi risposta

Zero. Le posizioni nel file si contano da 0, come gli indici di un array, ma si misurano in byte.

Prova tu

Calcola lo spazio

Con int da 4 byte, quanto occuperebbero cinque interi consecutivi? Dove comincerebbe il valore di indice 3?

Mostra soluzioneNascondi soluzione

Il file occuperebbe 5 * 4 = 20 byte. Il valore di indice 3 comincerebbe alla posizione 3 * 4 = 12. In generale usiamo numeroElementi * sizeof(int) e indice * sizeof(int).

Prossimo passo. Per trasferire questi byte ci servono soltanto un indirizzo e una quantità.
