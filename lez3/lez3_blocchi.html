read e write: due argomenti

Dove si trovano i byte? Quanti byte dobbiamo trasferire? Sono le due informazioni richieste.

← Precedente Successiva →

La direzione cambia, i dati restano gli stessi

write: memoria → file. read: file → memoria. In entrambi i casi indichiamo un indirizzo e il numero di byte.

write: dalla variabile al file

Frammento: out è un file già aperto per scrivere in modalità binaria.

&numero è l’indirizzo della variabile; sizeof(numero) è la sua dimensione in byte. La parte (const char*) permette a write di vedere quei byte senza cambiarli.

read: dal file a una variabile

Frammento: in è un file già aperto per leggere in modalità binaria, contenente l’intero scritto sopra.

Qui (char*) permette a read di scrivere nei byte di copia. Se la lettura non riesce, non usiamo la variabile come se contenesse un dato valido.

Il cast non trasforma il numero in testo: cambia il modo in cui passiamo l’indirizzo alla funzione. Usiamo la forma breve del cast C, già vista nella Lezione 0. Il trasferimento effettivo è eseguito da read o write.

Come aprire il file

Le aperture si usano nei rispettivi programmi, non contemporaneamente per questo esempio. ios::binary apre in modalità binaria; da solo non trasforma << o >> in operazioni binarie.

Checkpoint

La chiamata write salva anche il nome della variabile numero?

Mostra rispostaNascondi risposta

No. Salva solo sizeof(numero) byte a partire dal suo indirizzo. Nel file non compare il nome della variabile.

Scegli l’operazione

Quale chiamata useresti per salvare i byte di un int? E per scrivere le sue cifre in un file di testo?

Mostra soluzioneNascondi soluzione

Per i byte uso out.write((const char*)&numero, sizeof(numero)). Per le cifre uso out << numero. Sono due rappresentazioni diverse.
